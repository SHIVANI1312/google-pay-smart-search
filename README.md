# Google Pay – Smart Search
### Independent Product Management Teardown

**Project:** Google Pay India  
**Focus:** Improving feature discoverability  
**Proposed solution:** Smart Search  
**Project type:** Independent Product Teardown

## 1. Overview

This project explores how Google Pay users can discover existing features more easily.

The proposed solution introduces Smart Search, allowing users to search for features such as AutoPay and Split Expense directly from the home-screen search bar.

The objective is to improve discoverability without changing the existing feature interfaces.

## 2. Problem Statement

Users may need to navigate through multiple sections to discover certain existing Google Pay features.

This creates an opportunity to make feature discovery more intuitive and reduce navigation effort.

## 3. Proposed Solution

Introduce Smart Search.

Users can:
- Search for AutoPay.
- Select the AutoPay suggestion.
- Navigate directly to the existing AutoPay screen.
- Access the existing Live, Pending and Completed tabs.

The same approach can be extended to Split Expense and other existing features.
